
【操作】WASD 只负责走动；用鼠标右键在画面上拖拽可环视角色；左键点地块种花/浇水/收获。

【第一次在本电脑运行】
1. 装好 Node.js 后，在本文件夹地址栏输入 cmd 回车（或右键「在此处打开终端」）。
2. 输入：npm install    （只需做一次，装依赖）
3. 双击 run.bat，或输入：npm run dev
4. 浏览器打开窗口里显示的地址（一般是 http://localhost:5173）

【换 3D 模型】
把 .glb 文件放进文件夹：public\assets\
代码里写路径：assets/文件名.glb（参考 AssetLoader.ts 里的 loadGLTF）

【所有人做完后，只合并一次】
1. 把各人写的模块 .ts 文件都放进：src\modules\
2. 只改一个文件：src\modules\Registry.ts
   - 顶部多写一行：import { 某人的类名 } from './某人的文件名'
   - 下面数组里多写一行：new 某人的类名(),
3. 不要改 src\core\ 里的文件（除非大家都知道要改同一段）

【流程图 Demo 改哪改哪（避免多人改同一文件）】

【AI 接力规则（务必先读）】
1. 下一位 AI 先看：NEXT_AI_GUIDE.md
