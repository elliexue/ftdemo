# 资源规划（目录、槽位、格式与动作约定）

便于后续 **替换模型、检索素材、对接动画**。改资源时建议 **同步改本节表格** 与 `src/config/assetPaths.ts`。

---

## 1. 目录约定

| 路径 | 用途 |
|------|------|
| `public/assets/` | 默认 / 回退用 **GLB**（`npm run download-assets` 或手动放入） |
| `public/assets/custom/` | 自购 / 自解压资源包（当前为 Kenney OBJ 整包等） |
| `public/assets/custom/Models/OBJ format/` | OBJ + 同目录 MTL，贴图多为 `Textures/colormap.png` |
| `public/assets/THIRD-PARTY-MODELS.txt` | 示例 GLB 版权说明 |

**运行时不会联网下载**；离线只要把上述目录随项目拷贝即可。

---

## 2. 代码槽位 ↔ 文件（当前配置）

配置入口：**`src/config/assetPaths.ts`**（`loadModel`）。

| 槽位 key | 用途 | 优先资源 | 回退 | 加载方式 |
|----------|------|----------|------|----------|
| `player` | 第三人称角色 | **`assets/soldier.glb` 仅此**（Three 示例兵） | 无 | GLB |
| `plant` | 田里作物 / 花占位 | `…/animal-parrot.obj` | `assets/duck.glb` | OBJ 或 GLB |
| `lantern` | 远景装饰（小屋） | `…/building-type-a.obj` | `assets/lantern.glb` | OBJ 或 GLB |

- **路径前缀（Kenney）**：`assets/custom/Models/OBJ format/`（见 `KENNEY_OBJ`）。
- **`player`**：不走 `custom/`，只读 `public/assets/soldier.glb`；缺失时 `loadPlayerSoldier` 失败并保留胶囊占位，请执行 `npm run download-assets`。
- **其它槽位**：`custom` 失败 → `bundled`（控制台 `[assets]` 警告）。

---

## 3. 格式与引擎行为

| 格式 | 说明 |
|------|------|
| **GLB / glTF** | `loadGLTF`；可带 **骨骼动画**（见下节）。 |
| **FBX** | `FBXLoader` 仍可在 `loadSceneResource` 中使用；**人物槽当前未用**。 |
| **OBJ + MTL** | `loadOBJ`；**无动画**；贴图走 MTL 内路径（如 `Textures/colormap.png`）；URL 含空格目录已做编码。 |

实现位置：`src/core/AssetLoader.ts`（`loadSceneResource` 按扩展名分流）。

---

## 4. 角色动作约定（仅 GLB 有效）

**文件**：`src/core/Engine.ts` → `loadPlayerSoldier`。

引擎用 **`AnimationMixer`** 按 **动画片段名称** 查找：

| 状态 | 优先使用的 Clip 名 | 备选 |
|------|-------------------|------|
| 站立 / 不移动 | **`Idle`** | 无则只有跑时可能无过渡 |
| 移动（WASD） | **`Run`** | 若无则尝试 **`Walk`** |

- **OBJ 角色**：`animations` 为空 → **不会播骨骼动画**，只有模型随位移转向；要走路动作需换 **带上述命名的 GLB**（如 Mixamo 导出后可在 Blender 里重命名 Clip），或改 `Engine.ts` 里 `findByName` 适配你的 Clip 名。
- **已验证好用的示例**：Three 官方 **`soldier.glb`** — 含 `Idle` / `Run`，与当前逻辑匹配。

---

## 5. 田里「花」表现（程序几何）

- **逻辑**：`GardenModule` / `GardenPlanting` 等（与资源文件名无关）。
- **表现**：`GardenPlots` / `gardenPlantMeshes` 生成茎与默认花冠 mesh；`GardenVisuals.ts` 按 `SeedId` 切换 `HEAD_GEOMETRIES`，并按生长阶段 **缩放茎/花冠 + 配色**（含浇水施肥提示体与粒子）。

若以后要换 **GLB 真花**，可在 `GardenVisuals` 或单独模块里按 `plot.seedId` 挂接模型，并隐藏几何 `head`。

---

## 6. 远景槽位（lantern）

- 当前为 **小屋** OBJ 或 **灯笼** GLB，仅摆放与缩放，**无动画逻辑**。
- 鹦鹉曾作树占位已移除；要树可改 `SceneDecor.ts` 程序化或在此槽换 `tree-small.obj` 等。

## 7. 检索免费素材（自用书签）

| 站点 | 适合 |
|------|------|
| [Kenney](https://kenney.nl/assets) | 低多边形整包，CC0，OBJ/GLB 常有 |
| [Poly Pizza](https://poly.pizza) | 聚合 CC0，易预览 |
| [ambientCG](https://ambientcg.com) | PBR 贴图、地面 |
| [OpenGameArt](https://opengameart.org) | 需逐条看许可 |
| [Sketchfab](https://sketchfab.com) | 筛选可下载 + CC0/CC-BY |
| [Mixamo](https://www.mixamo.com) | 人形 + 动作 → 导出后转 **GLB**，注意 Clip 命名与第 4 节对齐 |

## 8. 后续替换 checklist

1. 文件放进 `public/assets/` 或 `public/assets/custom/...`。  
2. 改 **`assetPaths.ts`**：`plant`/`lantern` 的 `custom` 或 `useCustom`；**人物**改 `player.bundled`（当前仅 `soldier.glb`）。  
3. **若是角色且要走路**：确认 GLB 内 Clip 名含 `Idle` 与 `Run` 或 `Walk`，否则改 `Engine.ts` 查找逻辑。  
4. 更新 **本文件第 2 节表格**（记一句「什么模型好用」更好）。  
5. 大变更时在 **`docs/模块协作与变更记录.md`** 追加一行结果摘要。
