# 玩法说明（与当前代码一致）

面向策划 / 新同学：**游戏里已经实现了什么**。细节数值以源码为准（`src/modules/`、`src/game/`）。

---

## 1. 模块总览

运行时注册的玩法模块（`src/modules/Registry.ts`）：

| 模块 | 作用 |
|------|------|
| **GardenModule** | 中央 **5×4 共 20 块**自家田 + 西侧邻园 **4 块**田、种植/浇水/施肥/收获、邻园祝福与偷花、护院 AI、天气 tick、生长与特效；田里花冠为 **程序几何**（`GardenPlots` 茎 + `GardenVisuals` 按种子切换花冠） |
| **ArrangementModule** | 东侧插花台、三槽位展示、完成庆祝特效 |
| **UiModule** | 左侧 HUD（状态含**当前天气**、商店、清除存档、插花、种植说明、事件日志）、**数字键 1–0 选十种花**、**B** 开商店 |

角色移动、相机、射线输入在 **`src/core/Engine.ts`**（非 IModule）：**滚轮缩放**、**右键/中键拖拽**转视角；在**拜访好友**且射线命中**邻园田**时，**右键**交给花园模块用于**祝福**（不进入转视角）。

## 2. 自家花园（中央浅色木框田，20 块）

- **买种**：HUD 商店购买花种（**10 种**，金币消耗见 `types.ts` → `SEED_CONFIG.seedPrice`）。
- **选种**：侧栏种子按钮，或键盘 **1–9、0** 对应 `SEED_IDS` 顺序（1=郁金香 … 0=第 10 种，见 HUD 状态栏）。
- **播种**：空地（阶段 0）左键土面，消耗 1 粒当前选中种子。
- **生长**：阶段 **1** 时进度条随时间增长，受 **天气适性**、水分饱和度、祝福加成（来自邻园玩法，不直接改自家数据）、花精灵倍率（占位为 1）影响；满后进阶段 **2**。
- **浇水**：阶段 **1–2** 左键可浇水（阶段 2 在 `needsWater` 时浇水会**立即**进入阶段 3，并进入施肥等待冷却）；田里有**蓝色提示体**与**浇水粒子**（`GardenVisuals` + `gardenPlotEffects.triggerWater`）。
- **施肥**：阶段 **3** 在冷却结束后左键施肥，**立即**成熟至阶段 4；田里有**金色提示体**、**施肥粒子**与场景 **`triggerFertilize`** 碎粒（`GardenFertilizing` + `gardenPlotEffects`）。
- **收获**：阶段 4 左键，花进背包（品质见 `GardenHarvest.ts`）；稀有品相进背包带 `rare` 标记，卖价加成（`hudShop.ts`）。
- **特效**：种植弹跳、浇水涟漪、施肥碎粒、收获粒子（`gardenPlotEffects.ts`）。
- **花模型**：与迁移包一致——每株 **单茎 + 单花冠 mesh**，按 `SeedId` 换 `BufferGeometry`（见 `GardenVisuals.ts` 中 `HEAD_GEOMETRIES`），随阶段缩放茎高与花冠大小。

## 3. 天气系统

- 全局天气四种轮替：**晴天 / 多云 / 雨天 / 微风**（约 **36 秒**切一种，见 `GardenWeather.ts`）。
- 每种花有 **适性天气**：一致则生长更快，不一致略慢（倍率在 `SEED_CONFIG`）。
- **HUD 状态栏**显示当前天气图标与名称；切换时 **pushLog** 提示。

## 4. 邻园（西侧偏紫木框四块田）

与自家**同屏**，数据为 **`gameState.friendPlots`**，由 `socialMock.initFriendGarden` 初始化；空地块定时随机补种（`friendGardenSpawn.ts`）。

### 4.1 主人（护院）行为

- 默认在地图他处 **巡逻**。
- 你对邻园花做过 **祝福成功** 或 **盛花左键偷花尝试**（含失败）后，主人 **赶回花田**，进入 **守园追击**；速度倍率 **`friendChaserSpeedScale`** 可存档。
- **被追上**：贴近时 **传送回出生点** `(0, 约 0, 5)`（`game:respawn-player`），有冷却（见 `friendGardenChaser.ts`）。
- 你离开警戒范围一段时间后，主人回岗再 **外出溜达**。

### 4.2 祝福

- **生长期（阶段 1–3）**：**左键或右键**地块 → 金币谢礼 + `blessBonus`；小概率 **稀有变异** `rareVariant`（花冠偏金，见 `socialBless.ts`）。
- **盛花（阶段 4）**：**右键**祝福 → 更高金币与变异逻辑；成功有 **金色粒子**（`triggerBless`）。
- 引擎在「拜访好友」且射线命中邻园田时，**右键不会进入转视角**，而是交给上述逻辑。

### 4.3 偷花

- **左键**成熟花（阶段 4）：按 **`STEAL_SUCCESS_RATE`**（默认约 **58%**，见 `socialSteal.ts`）判定成功与否。
- **成功**：花进背包，地块清空；若地块为 **`rareVariant`**，背包花朵带 **`rare`** 标记，卖花时有加成（`hudShop.ts`）。
- **失败**：日志提示被护院发现；**无论成败**，都会触发 **`noteFriendGardenTouched`**，邻园主人会 **赶回并可能追击**（与祝福成功相同）。
- **HUD**：切换到「拜访好友」时，状态栏会显示完整 **偷花说明**（成功率、稀有、护院、右键祝福与视角规则）。

## 5. 商店与背包

- **卖花**：一键卖出全部（基础价 + 品质 + **稀有加成**）。
- **背包花**：用于插花；数据在 `gameState.flowers`。

---

## 6. 插花（东侧圆毯插花台）

- 位置见 `arrangementStation.ts`。
- HUD **插花**区：按品种放入三格；**完成作品**得金币与日志；**清空**重置槽位。
- 展示：**优先** `animal-bunny.glb` / `animal-cat.glb` 或 Kenney OBJ。**玫瑰、木槿**（代码中对应原「猫模板」分支）→ **猫**，其余 → **兔**；失败用色块占位（`ArrangementModule.ts`）。
- 完成时有 **金粒喷发**；槽位约 **0.78s** 后清空，庆祝期间小动物仍留在台上。

---

## 7. 操作与存档

- **移动**：WASD；**跳跃**：Space；**视角**：右键或**中键**拖拽；**缩放**：**滚轮**。
- **左键**：点自家田、插花台等（自家田无右键交互）。
- **拜访好友 + 邻园田**：**左键**偷成熟花或祝福生长期；**右键**祝福（含盛花）；点到空白处仍可用右键拖视角。
- **存档**：`localStorage`（`saveLocal.ts`），订阅状态防抖写入。
- **清除存档**：HUD **「清除本地存档」**，恢复默认 20 块自家田、种子与天气等，并 **`initFriendGarden` 重置邻园模拟田**（邻园进度本身不写入存档）。
