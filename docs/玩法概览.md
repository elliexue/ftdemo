# 玩法要点

玩家向简述；不写技术细节。

---

**地图**

- 中央：自家花田（种、浇、肥、收）。
- 一侧：邻居花田（祝福、帮忙、偷花）。
- 东侧：插花台（三格摆花 + 蓝开关合成花束）。

**操作**

- WASD 移动，空格跳跃。
- 右键/中键拖视角，滚轮缩放；左键点田、展台、场景按钮。
- B 或界面按钮开商店；底栏或数字键 1–0 选种。
- 邻居田：右键多用来祝福；左键可帮忙照料或（成熟时）偷花；靠近成熟花有「祝福 / 偷取」提示。

**种田**

- 商店买种 → 空地播种 → 按阶段浇水、再施肥 → 成熟收获。
- 天气会变，影响部分花的生长快慢；状态栏可看当前天气。

**邻居**

- 祝福：加速生长或把盛花变成超大花，有金币；**不触发**主人追赶。
- 帮忙：生长中左键可帮浇水、施肥。
- 偷花：成熟后概率成败；**一偷就**会引来主人追击，太近会被送回出发点。

**经济**

- 金币：买种、祝福奖励、卖花、卖花束。
- 商店里**卖鲜花**与**卖花束**分开按钮。

**插花**

- 走近插花区才弹出插花界面。
- 先选背包里的花，左键摆上三个展台 → 按蓝开关合成 → 花束进背包可卖。

**界面与存档**

- 左上：商店、清存档、操作提示；右上：事件记录；左侧：状态与背包；底部：选种。
- 存档在本机；清存档即恢复默认开局。
